The custom `SuccubusPerformer` inspector also shows read-only current runtime booleans in Advanced. They are telemetry, not authoring values or capability preflight. `PerformanceSceneBindings` exposes `RequiresPlayer` and `RequiresToys`, `DeclareAssets`, and `DeclareSeats` for sequence declarations. Its Teleport capability validates the teleport profile; seating declarations validate exact approach/seat anchors, baked profile/frame capture, and scene ownership. Visibility preflight rejects a particle body targeting another actor's renderer. The inspector reports owner/property paths and offers its scoped wire action without starting playback or finding arbitrary scene objects.

The optional `SceneBindingMigration` command works only within the selected scene hierarchy. It refuses missing or ambiguous player/toy/clock sets and conflicting existing references; successful edits use Undo, record prefab overrides, and mark the scene dirty. It performs no runtime/global discovery.

## Apply-to-defaults behavior

`PerformerDefaultsEditor` snapshots each saved scene actor and same-object grip controller before Play Mode as paired identifiers: a stable EntityId string captured for finding that instance in Play Mode, and its edit-mode `GlobalObjectId` for applying after Play Mode. GlobalObjectIds change in Play Mode, so QueueApply resolves the current component's EntityId to the pre-Play GlobalObjectId instead of comparing play-mode GlobalObjectIds. The saved snapshot excludes unloaded, unsaved, and preview scenes. Queueing requires Play Mode, a saved scene path, and an EntityId captured before Play Mode; it rejects actors or grip controllers created during Play Mode. Capture catches unsupported serialized property types and returns the error to the inspector. On returning to Edit Mode, the delayed apply checks property paths and types, records Undo and prefab-instance overrides, marks the component/scene dirty, then clears the queue.

The current supported values are:

- performer: `defaultTransition`, `defaultExpressionBlendTime`, `initialExpressionIntensity`, `motionOwnershipBlendSeconds`;
- performer: breathing values/curve except `breathingBones`, morph/chest/belly/bone enable and strength, all gaze fields, attention/eye-fixation/head-attention fields, and all blink fields;
- same-object grip controller: `gripStrength01`, `wristTwistDegrees`.

References, setup bindings, rig channel maps, placement, player/camera values, profile/catalog/config assets, calibration, diagnostics, wardrobe drafts, and test controls are excluded. Apply writes only saved scene-component instances; it never writes shared ScriptableObject assets. Save the scene before entering Play Mode.
