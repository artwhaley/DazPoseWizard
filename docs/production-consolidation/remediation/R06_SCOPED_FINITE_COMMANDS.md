# R06 — one finite-command kernel

Depends R05. Allowed seams: new Authoring types from CONTRACT, PerformanceExecutionScope, narrow cancellation-token hooks in existing owners. No new scheduler or changed low-level result enums.

1. Implement PerformanceRun.Begin with runtime preflight, main-thread requirement, required bound actor availability, one private scope and immutable bound references. Begin throws a diagnostic exception before playback on invalid bindings. Stop records stopped state and cancels exact owned work once; Dispose calls Stop. First failure is retained and later cleanup errors do not replace it.
2. Implement private `Execute<T>` taking start factory, success predicate, exact cancellation capture and internal verb label. This API is private/internal; authors never see channel/predicate parameters. Check run state before calling start. Register operation/cancellation before consuming the underlying Awaitable. Capture synchronous start exceptions and stop siblings. Only one observer awaits the raw operation; a separate completion source supplies the author's Awaitable.
3. Forward success original T; translate explicit Stop into OperationCanceledException; unexpected failed/superseded/disabled result into PerformanceCommandException. Include actor/verb/original status and wardrobe failure code/reason. Cancellation racing completion settles the author's completion once. No async-void exception escapes observation.
4. Implement ScopedPerformer methods with existing primary parameters/defaults: PoseAsync, ExpressionAsync, SayAsync, WalkToAsync, TurnToAsync, SitAtAsync, StandUpAsync, PerformAsync, GestureAsync, DissolveInAtAsync, DissolveInAsync, DissolveOutAsync, DissolveToAsync, TeleportToAsync, OutfitAsync, SetHairAsync, TryRemoveLayerAsync, TryAddLayerAsync, GripAsync, CastAsync. Preserve Transform/Vector3, preset/string and existing explicit timing/style/transition overloads where present; signature coverage is checked in R08.
5. Success table: pose/expression Settled; speech Finished; locomotion/teleport/DissolveTo Arrived; DissolveIn/DissolveInAt Visible; DissolveOut Hidden; seating Seated for SitAt and Standing for StandUp; action/gesture/spell Completed; grip Acquired; wardrobe Applied/AlreadyEquipped/NoChange. Everything else is non-success except deliberate Stop, which cancels. Preserve no-op structured wardrobe results for branching.
6. Delay uses scaled Time.deltaTime but checks Stop before/after each frame. Overlap is achieved by starting two scoped calls and awaiting their separate results; no global queue or forced serialization.

Run `-Ticket R06`: successful serial calls; synchronous validation exception; unexpected typed result; concurrent speech/gaze does not block; first failure cancels pending siblings; Stop before start, during request, during pause; Stop/finish race; twice Stop; external replacement survives stale cancellation; exactly one raw Awaitable consumption. Use actual typed results, not matching enum strings.

Gate: authors can await scoped verbs without channel/expected-enum plumbing. Persistent acquired work is completed in R07; do not advertise lifetime coverage until then.
