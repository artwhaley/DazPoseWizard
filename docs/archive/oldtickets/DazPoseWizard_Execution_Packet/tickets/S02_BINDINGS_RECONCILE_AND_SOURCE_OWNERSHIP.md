# S02 — Automatic typed content + scene bindings reconciliation

**Depends:** S01. **Goal:** the author never edits serialized YAML arrays or types list by hand.

Create `SourceBindingReconciler` (Editor) and stable `SourceBindingManifest` derived from S01; generate/manage adjacent same-basename `StoryContentBindings` for new local scripts/global card scripts only once. Auto-populate poses, gestures, magic, motion, dialogue and symbolic scene requirement declarations with correct types and source references. Existing objects preserved by semantic key and Unity GUID on recompile, rename or source move. `StoryContentBindings.sceneSymbols` should be derived, never extra typing burden. For dialogue use unchanged `StoryDialogue.IdFor` key and explicit transcript; changing a sentence moves old entry to `Unused` and new clip unbound. `posture` remains author-provided per pose (default safe Standing but clearly editable in generic tool; don't hardcode First Contact postures in CustomEditor). Remove manual `Refresh dialogue entries from source` as a REQUIRED workflow; can keep a safe Refresh button for recovery. Reconcile is idempotent: same source twice produces no asset dirty/bytes diff; property edits remain Undo-supported.

Scene binding reconciliation operates on **active saved scene host**: matches requirements for transform/location/seat/camera, performer/playerbody/contact and creates missing typed records only when explicitly attached/initialized. Do not make up spatial coordinates or auto-spawn random marks. Provide action `Create Mark at Preview Placement`, then author positions it visually; record Undo/dirty. Reuse current `StorySceneBindings.locations`, preserving existing FirstContact marks/IDs/seats. Scene roles bind to existing actual Lara/player body/host, not clones. Type check wrong asset/duplicate symbol; show unused/renamed ambiguous entries for author action. Global selectable card sources retain source-owned companions, no scene membership.

Tests: new script+new scene, content binding auto-created, correct typed empty rows; assign pose WAV then reimport; rename/move retains values; delete statement orphan safe; reused symbol single binding; source type collision diagnostic; no-op second sync does not dirty; existing FirstContact old `.bindings.asset` byte identity or explain any schema migration with preserved references.

**Gate:** Source compile→binding manifest→ready asset with drag/drop only; current scene saved marks stable; no manual YAML or duplicate FirstContact-specific ID lists.
