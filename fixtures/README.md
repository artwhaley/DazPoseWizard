# Local DAZ fixtures

Place the licensed local test files in `fixtures/private/`:

- `Genesis8Female.dsf`
- `Cherish Genesis 8 Female 16.duf`

The private fixture directory is gitignored. DAZ figure, pose, and FBX assets are not committed. Fixture-based integration checks auto-skip when these two local files are absent. The test suite covers Genesis 8 Female only in this first version.
