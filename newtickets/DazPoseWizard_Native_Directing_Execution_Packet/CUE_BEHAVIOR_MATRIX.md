# Cue behavior matrix — authoritative end-state semantics

**Purpose:** prevent the executor from making up choreography, camera endpoints, pose resets, or cosmetic approximations in a fake viewport. The canonical story interpreter continues to own control flow. The native visual stage consumes its **ordered, executed commands** and re-resolves their scene-linked effects to build a *cumulative* visual state. The stage does not call runtime asynchronous performer or player methods in Edit Mode.

The terms **pose/rest** and **endpoint** refer to the end of the authored command, not the start of its animation. Stage a settled/resting pose when such a pose exists; animate/scrub only when the project already provides reliable edit-time sampling and the author requests it.

## Accumulation rules

1. **Ordered source effects**, not text-recognized code, form a read-only cue presentation projection. First `Camera.StartAt` establishes root+orientation; later `Camera.Track` alters orientation policy, not root. Later `Lara.LocomoteTo` changes performer root but does not erase the current persistent pose or camera anchor. `Lara.Say` changes neither.
2. The projection records **semantic references** (e.g., `Lounger.SeatAnchor`, `stepforward`, `camera_start`), not baked-only world coordinates. When the author moves one of those marks, resolve the same logical state against the **new authored transforms** immediately—without replaying random decisions.
3. Restaging is **idempotent**: apply baseline-plus-projection, never multiply offsets or repeatedly deform bones. Frame-dependent effects have a definite chosen sample time/end state or an explicit limitation.
4. The native stage must not write authored location/seat/camera anchors. **Exception in observation only:** actor-descendant `laraFocus` moves in world space as a consequence of Lara bone sampling. Preserve its authored local transform, compute camera aim after pose sampling and never use its stage-driven world delta to invalidate the logical cue. Track source anchor matrices and parent moves separately from preview-owned actor changes.
5. Before/After selection and nth-visit navigation remain distinct, with source and actual global card owner visible. A visually unchanged cue (e.g., dialogue) is still successfully executed and should show valid cumulative composition.
6. If a scene path has no endpoint, invalid seat, missing camera or unresolved binding, **stop transport at the offending cue with a visible source-aware error**. Do not drain subsequent queued visual effects and overwrite the failure with a later valid shot. A supported nonvisual cue still advances logic; an unsupported **visual** command used in acceptance is incomplete until implemented or Art explicitly changes scope.
7. **Source verification required per row:** cite runtime method and command parameters in regression report. `StartHiddenAt`/`DissolveInAt`/`Camera.StartAt` use full mark rotation where runtime says so, standing `DissolveTo` uses yaw-only and snaps to initial pose, `SitAt` differs from pose-persistent seating. Do not extrapolate one command's convention to another.

## FirstContact end-to-end acceptance oracles

- `Lara.StartHiddenAt(lara_start)` then `Lara.DissolveIn` sets one Lara root and toggles visible state safely.
- `Lara.LocomoteTo(stepforward)` followed by `Lara.PersistentPose(SexyVamp)` leaves Lara at stepforward with the pose in **Scene and Game** views. Dragging `stepforward` updates both without replay.
- `Camera.StartAt(camera_start)` stages actual `PlayerView` rig; `Camera.Track(Lara)` updates aim as Lara moves on subsequent cues. Dragging `camera_start` updates Game view continuously.
- **First seat (Warmup):** `Lara.SitAt(Lounger)` stages seat's default stable CrossLegs/baked endpoint; following `Lara.PersistentSitPose(Lounging)` samples Lounging and corrects the **sampled hip** to SeatAnchor. This is *not* the Intro standing Lounger dissolve. Test both adjacent cues in native Editor.
- **Later seat (Main):** after a Director-loop visit `Lara.DissolveTo(Lounger, seated: Lounging)` stages a pose-specific hip-corrected seated endpoint. Move SeatAnchor to update pose/framing, ApproachAnchor only affects approach diagnostics; test independently from Warmup.
- An awaited gesture completes on **underlying pose**; a non-awaited gesture's observation is explicitly labelled. A MagicShader effect must reach the actual material endpoint or be marked incomplete pending Art approval; no unreviewed blanket no-op.
- A later `Lara.DissolveTo(MainPosition1)` returns standing composition; body/contact appearance in Climax follows authored commands.
- Director loop with different selected global cards and a changed seed uses identical canonical logical choices to the previous managed rehearsal, and shows authored body states.
- Save while any cue is staged persists only deliberate authored anchors/bindings; no animated skeleton/visibility/material/camera preview values serialized.
