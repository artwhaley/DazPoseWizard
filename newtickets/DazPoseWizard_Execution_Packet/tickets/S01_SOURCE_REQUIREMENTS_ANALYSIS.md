# S01 — Analyze `.dazstory` without any preexisting asset bindings

**Depends:** U07. **Goal:** Fix the importer/compile chicken-and-egg, generic for all future scenes/cards.

Current importer invokes `DazStoryCompiler.Compile(text,path,asset.content.Symbols(),allowExternalCards:true)`, so it is not a true source-first binding experience. Add `DazStoryCompiler.Analyze(source,path,options)` that parses syntax/vocabulary and derives typed `StoryBindingRequirement` from `StoryVocabulary` binding parameters, literal `Lara.Say`, source declarations, `setup` roles, `play`, and all reachable calls, **independent of assigned Object references**. `StorySource` with original declaration/line/column; explicit symbol-type collisions and unknown verbs become errors. Differentiate real compile errors from unresolved typed requirements. Output `SourceAnalysis { Program?, Requirements, SyntaxDiagnostics, UnresolvedAssignments }`; the final `CompiledStoryProgram` remains executable via existing runtime after binding readiness check, with local and globally linked cards unaffected. Define requirement ID using source GUID + kind + alias; dialogue stays existing SHA256 transcript key. Multiple references to same symbol share one requirement and include occurrence list. Free-form/dynamic asset names not statically resolvable should produce a compile diagnostic explaining how to make it resolvable; do not hide in silent empty row.

Importer version increment only when needed; preserves .dazstory GUID, compiled subasset identity where safe, and backward compatibility for old client calls. New source with zero bindings parses and presents e.g. `SexyVamp Pose`, `Bedside Location`, `"Hello" AudioClip` typed unbound rows. Existing FirstContact still compiles/runs identically. Tests pure C# fixture new unbound source, collisions, bad verbs/args, many calls same alias, dialogue change, 32 nested blocks, cross-source cards and unchanged golden source/seed.

**Gate:** A brand-new .dazstory can be analyzed without a `.bindings.asset`, produces typed manifest and source locations, with clear no-source-assignment `BindingsIncomplete` not false fatal syntax status. No manually typed symbol arrays required to get this far.
